## 🛠️ Kurulum

1. Oyunu tamamen kapatın.
2. ZIP paketinin tamamını bir klasöre çıkarın.
3. **Kurulumu-Baslat.cmd** dosyasını çalıştırın.
4. `cod.exe` ve `sp26` klasörünü içeren **ana oyun klasörünü** seçin.
5. **Yedekle ve kur** düğmesine basın, ardından oyunu açın.

Kurucu üç dosyayı yükler:

```text
dxgi.dll
sp26/dxgi.dll
sp26/trdata2.bin
```

Mevcut dosyalar oyun klasöründeki `TurkceYama-Yedek-*` dizinine yedeklenir. Yedekteki `Geri-Al.cmd` ile kurulumu geri alabilirsiniz.
